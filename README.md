# QA evidence

Screenshots and other visual evidence for the QA reports in `odd/qa/` on `main`.

They live on this orphan branch because Orca installs Jev Advisor by cloning a
release tag and refuses a plugin tree over 50 MiB; a tag clone never fetches
this branch. Paths here match the paths the QA reports name, so
`odd/qa/screens-0.7.0/x.png` on `main` is `odd/qa/screens-0.7.0/x.png` here.
